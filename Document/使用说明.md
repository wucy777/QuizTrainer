# QuizTrainer 使用说明

一个通用的选择题刷题工具。**不内置任何题目**，题库由你以 JSON 文件导入。

---

## 一、开始使用

1. 打开程序
2. 点 **导入题库 JSON**，选择你的 .json 文件
3. 开始刷题

导入成功后会保存在本机，**下次启动自动载入**，不用重复导入。
在 **配置** 页可以看到已导入的题库并逐个移除。

> 题库格式见同目录 `题库JSON格式说明.md`。

---

## 二、界面

```
┌──────────────────────────────────────────────┐
│ QuizTrainer   [题库▾] [导入] [配置] [错题本]    │
├──────────────────────────────────────────────┤
│ 题号 · 分类                                   │
│ 题干（大字）                                   │
│ 说明 / 提示 / 译文                             │
│ ┌ A) 选项一 ────────────────────────────┐     │
│ ┌ B) 选项二                             │     │
│ ┌ C) 选项三                             │     │
│ ┌ D) 选项四                             │     │
│ ✔/✘ 结果提示                                  │
├──────────────────────────────────────────────┤
│ [←上一题][下一题→][交卷]     第1/60 · 已答0   │
└──────────────────────────────────────────────┘
```

- 点选项作答
- 底部显示进度与已答数量
- 选项支持 2~15 个，长选项自动折行、可滚动

---

## 三、两种作答模式

配置页有一个**主勾选框**和**两个互斥联动的子勾选框**：

| 模式 | 主勾选框 | 子勾选框 |
|---|---|---|
| **A. 点一下就答** | ☑ 单击选项即提交为答案 | ☑ 立即显示对错并展示答案 |
| **B. 全部打完再交卷** | ☐ 不勾选 | ☑ 选择选项后自动进入下一题 |

- **模式 A**：点选项立刻判分。可以关掉"立即显示对错"，只记录不显示。
- **模式 B**：点选项只记录、不判分；全部打完点 **交卷** 统一判分。
- 主勾选框勾选时，子勾选框是"是否立即显示对错"；取消勾选后，子勾选框变成
  "选择后是否自动进入下一题"。两个子勾选框按主勾选框的状态互斥启用。

其他配置：

| 配置 | 作用 |
|---|---|
| 切换题库时打乱题目顺序 | 随机打乱，避免记住位置 |
| 把中文说明放在题目上方 | 默认说明在题干下方，勾选后放上方 |

设置自动保存。

## 四、颜色含义

| 颜色 | 含义 |
|---|---|
| 🔵 蓝色 | 你选的选项 |
| 🟢 绿色 | 答对了 / 正确答案 |
| 🔴 红色 | 你选错了 |
| 🟡 黄色 | 答错时标出正确答案 |
| 灰色 | 无关选项 |

---

## 五、错题

- 点 **错题本** 随时查看
- 全部答完点 **交卷** → 成绩单（得分 + 错题列表）
- 成绩单里可 **导出 JSON**（格式与题库相同，能再导入重刷）
- 可点 **重刷这些题** 立刻只刷错题

导出时在 Windows 上会弹保存对话框；在 Android 上若无权限会自动改为**复制到剪贴板**。

---

## 六、平台说明

### Windows
- 有**单文件版**（一个 exe，双击即用）和文件夹版两种
- 单文件版首次启动会把内置程序解压到 `%TEMP%\QuizTrainer_<PID>`，
  **程序退出后自动删除**，不留残留

### Android
- 直接安装 apk 即可，Android 5.0 及以上
- 未配置签名时是 debug 签名，自己装没问题，但不适合上架
