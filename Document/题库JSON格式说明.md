# 题库 JSON 格式说明

本程序不内置题目，题库一律以 JSON 文件导入。本文说明这个格式。

按此格式整理任何科目的选择题，都能直接导入刷题。

---

## 一、最小示例

```json
{
  "题库名称": "示例题库",
  "题目列表": [
    {
      "题目": "光在真空中的传播速度约为多少？",
      "副题目": "提示：约 3×10^8 m/s",
      "正确答案选项": "A",
      "选项": {
        "A": "3×10^8 m/s",
        "B": "3×10^6 m/s",
        "C": "3×10^5 m/s",
        "D": "3×10^10 m/s"
      }
    }
  ]
}
```

---

## 二、字段说明

### 顶层（整个文件）

| 字段 | 必填 | 说明 |
|---|---|---|
| `题库名称` | 是 | 显示在程序里与题库下拉框中 |
| `题目列表` | 是 | 数组，每个元素是一道题，不能为空 |

### 每道题

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `题目` | 是 | 字符串 | 题干 |
| `副题目` | 是 | 字符串 | **说明栏**：提示、译文、考点解读等，不需要就填 `""` |
| `正确答案选项` | 是 | 字符串 | 答案字母，必须存在于 `选项` 里 |
| `选项` | 是 | 对象 | 键为 `"A"`~`"O"`（必须大写字母），值为选项文字 |
| `题号` | 否 | 字符串 | 如 `"Q12"`，只用于显示。**可以重复** |
| `分类` | 否 | 字符串 | 如 `"第一单元 · 单选"`，用于分组显示 |

`副题目` 是给题目配一段说明用的。外语题可以放译文，中文题可以放提示或解析；
程序界面上它显示在题干下方（可在配置里改成上方）。

---

## 三、程序会强制校验的规则

导入时逐条检查，任何一条不满足就**拒绝加载并弹窗说明原因**，不会影响当前正在刷的题库：

1. 顶层必须是 JSON 对象，含 `题库名称` 和 `题目列表`
2. `题目列表` 必须是非空数组
3. 每题必须含 `题目` / `副题目` / `正确答案选项` / `选项` 四个字段
4. `选项` 必须是对象，键为**单个大写字母**（`"a"` 这种小写会被拒绝），至少 2 个，值不能为空
5. `正确答案选项` **必须存在于选项键中**
   —— 例如只有 A/B 两个选项却填 `"C"`，会报错：`正确答案 C 不在选项 A/B 中`
6. 题干不能为空
7. 题干与说明里不能有整理残留标记：`✅`、`【B】`、`-> C`

第 5 条专门用来防"选项只写到 D、答案却写 E"这类错误，加载时就会被拦下。

---

## 四、支持多选

`正确答案选项` 可以写成数组，表示多选题：

```json
{
  "题目": "以下哪些是哺乳动物？",
  "副题目": "",
  "正确答案选项": ["A", "C"],
  "选项": {"A": "鲸", "B": "鲨鱼", "C": "蝙蝠", "D": "鳄鱼"}
}
```

单选与多选可以在同一个题库里混着放。多选题需要选够再提交，判定为完全匹配。

---

## 五、选项个数不受限

程序支持 **2 ~ 15 个选项**（A~O），长选项会自动折行，选项多时界面可滚动。

例如"从词库中选词填空"这类题型，把词库做成 A~O 的选项即可：

```json
{
  "题号": "Q26",
  "题目": "People tend to want as many choices as possible. They believe this will maximize their ______ of making the best decision.",
  "副题目": "chance 机会",
  "正确答案选项": "C",
  "选项": {
    "A": "approximately", "B": "case", "C": "chance", "D": "confused",
    "E": "crucial", "F": "deposited", "G": "enter", "H": "invest",
    "I": "matter", "J": "presented", "K": "range", "L": "regular",
    "M": "seize", "N": "selection", "O": "ultimately"
  }
}
```

同理，"把段落编号作为选项"的匹配题也能放进来。

---

## 六、导入方式

**Windows / Android 程序**
- 点 **导入题库**（空状态页有按钮，主界面在右上角）→ 选择 .json 文件
- 校验通过后题库会保存在本机，下次启动自动载入
- 可随时导入新 JSON；同名题库会被覆盖
- 在 **配置** 页可查看已导入的题库并逐个移除

程序**不内置任何题库**，所有题库都靠导入。

---

## 七、错题导出

刷完点 **交卷** → 弹出成绩单，可点 **导出为 JSON**。
导出文件是**同样的规范格式**，可以直接再导入重刷，也可以自己编辑后当新题库用。

---

## 八、注意事项

- 文件编码用 **UTF-8**（带不带 BOM 都行）
- 语法要合法：逗号、引号别漏，最后一个元素后面不要多加逗号
- 建议用 VS Code / Notepad++ 编辑并另存为 UTF-8，避免中文乱码
- 一个 JSON 文件 = 一个题库
- 题号重复没关系（程序内部用位置索引区分），但建议保持可读
